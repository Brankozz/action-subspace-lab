Method notes / v1.0

01共同成分与低维变化

完整示范重采样到 64 步，按训练集的每通道尺度标准化，对中心化的整条轨迹做 PCA。μ 是任务平均模式，U 是正交变化模式；低秩说的是示范之间的变化维数。

xᵢ = μτ + Uτ,k zᵢ + εᵢ

在验证集首次达到 ≤ 0.10 的相对表示误差时选 k；若未达到，则在候选范围内取误差最小值。均值也会混入场景偏置，不直接等于“语义”。

02从当前环境预测系数

使用训练示范的初始末端位置拟合岭回归 ẑ = Wc + b，正则强度用验证集选择。打乱训练条件的对照帮助判断条件是否有信息。条件特征必须仅来自第 0 帧。

‖x − μ − Uẑ‖² = ‖ε‖² + ‖z* − ẑ‖²

“留出”来自示范内部划分，不是 LIBERO 官方环境测试成功率。下一步应在独立初始场景中闭环执行动作块，测量任务成功率。

03把语义作为可检验的条件

跨任务模型可写为全局均值、指令相关成分与环境相关变化之和。比较文本特征和共同成分的关系，再用任务与场景分组留出验证；需要控制环境与指令的相关性。

xτ,i = μ₀ + s(ℓτ) + Uτ z(cᵢ) + ετ,i

线性模型不足时，再考虑分阶段基底、混合子空间或条件生成模型。不同绕障策略的均值可能穿过障碍；可重建与可执行必须分开检验。

如果原始 action 不够低秩，下一步用什么数学模型？

优先分离时间与空间：同样的抓取如果发生在不同时间，直接平均会把动作冲淡。先用可观测的夹爪切换、接触或运动阶段划分“接近—抓取—搬运—放置”，在每个阶段做轨迹 PCA；如果离线使用完整测试动作做动态时间规整，必须将结果标为事后表示上限，不能当成可部署策略。

其次，把绝对世界坐标换成相对于目标物体和放置位置的坐标。任务语义更可能对应这种相对运动规律，而不是某一组固定的世界坐标动作。连续末端运动与离散夹爪状态也应分开建模。

aₜ = μℓ,qₜ(sₜ) + Uℓ,qₜ(sₜ) zₜ,   (qₜ, sₜ, zₜ) ∼ pθ(· | o≤ₜ, ℓ)

这里 q 是动作阶段，s 是阶段进度，z 是变化系数。当前观测决定这三者，语言决定任务先验。每次仅执行一个短动作块，再根据新观察重新推断；多种可行策略则保留系数分布或混合子空间，而不是把所有策略平均成一条可能碰撞的路线。最终按初始场景分组留出，并用仿真成功率检验。

数据、误差定义与导入格式

LIBERO 样本来自原分析台的量化示范副本。每条示范只进入一个划分；不按帧随机切分，不利用完整留出动作拟合尺度、共同成分或基底。长度归一化移除了时长差异，因此不检验速度或持续时间预测。如果多条示范共享初始场景，进一步验证必须按场景 ID 分组。

岭回归最小化训练系数平方误差加 λ‖W‖²。λ 候选为 0.1、1、10、100、1000、1000000，按验证集推荐维数下的系数误差选择；打乱条件的对照独立选择 λ。移动维数滑块不会重新调参。大 λ 接近只用任务均值。

表示误差为 Σ‖x − μ − UUᵀ(x − μ)‖² / Σ‖x − μ‖²，Σ 遍历留出示范。条件误差替换为预测 ẑ；分母为零时显示“未定义”。夹爪按连续值分析，尚未单独评价二值切换或碰撞约束。

支持原分析台压缩 JSON 或下面的完整示范 JSON。data 各字段是按时间排列的一维数组，长度为 T × dim。每个任务至少 15 条示范；没有初始条件时停用预测。数据只在浏览器读取。

{"name":"my-demos","fields":[{"name":"action","dim":7},{"name":"eepos","dim":3}],
 "groups":["pick up the bowl"],
 "episodes":[{"id":0,"group":0,"T":64,
   "data":{"action":[...448 numbers...],"eepos":[...192 numbers...]}}]}

导出保存训练均值、尺度、基底、当前 k、划分和诊断结果。手动合成没有经过物理执行验证。
