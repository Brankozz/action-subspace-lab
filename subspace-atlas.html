Method notes / v2.0

01对一个任务的训练全集建模

不拆分训练示范。全部轨迹线性重采样到 64 步，以全集的每通道标准差统一尺度，再对中心化的完整轨迹做 PCA。μ 是任务平均模式，U 是正交变化模式。

xᵢ = μτ + Uτ,k zᵢ + εᵢ

默认 k 是累计解释 90% 训练变化的最小维数。低秩描述示范之间的变化，不意味着任意系数组合都能执行。均值也可能包含场景偏置，并不直接等于语义。

02只依据观察，采样测试候选

给定初始观察 c，用训练观察的标准化距离计算高斯邻域权重。先按权重选一个训练系数中心，再加按各模式标准差缩放的高斯扰动。无条件时各中心等权。

wᵢ(c) ∝ exp(−d(c,cᵢ)² / 2h²)
z = zⱼ + T · diag(σz) ε,   j ∼ w

h 是观察邻域带宽，T 是扰动倍数，ε 是标准正态向量。这是可解释的候选提议分布；观察距离不评价任务成功，也不会利用测试动作来选择候选。

03在测试环境中判断候选

当前页面没有机器人执行器或成功判断器。独立测试环境不需要 action：先输入当前观察，在训练空间中提出候选，再通过仿真、环境反馈或学习到的价值函数判断。

候选 z → μτ + Uτ,k z → 环境反馈

进一步可用观察历史预测阶段、进度与系数，每次执行短动作块再重新采样。多种策略应保留为多个候选，避免直接平均出碰撞路线。

几何场景和末端路径从哪里来？

场景来自本地 LIBERO / MuJoCo 模型的碰撞几何与初始化状态，以世界坐标、米为单位绘制。方盒等几何保留容器开口、桌面和柜体的主要空间关系；它们不包含原始纹理。训练数据未保存每条示范的完整物体位姿，因此训练侧展示同任务参考布局，不能当作该条示范的精确物体位置。已有评测观察按对应初始化恢复，页面会单独标明。

选择“末端位置”时，训练参考是实际记录的世界坐标 EEF，其他曲线是该信号的子空间合成。选择 action、平移动作或累加信号时，用全部配对训练示范学习 EEF ≈ μ_EEF + Bz，把同一组系数映射为末端路径的几何估计；图中的训练 RMSE 只描述拟合，不证明候选能在环境中执行。没有把 action 数值直接当成米。

“对齐到当前观察起点”仅对显示路径作显式平移，不修改 action 或采样系数。播放功能显示轨迹进度，场景物体保持初态；没有进行碰撞检测、抓取模拟或成功判定。

时间对齐、动作语义与使用范围

当前只有线性进度对齐，没有按抓取等事件对齐，也不预测原始执行时长。若同一动作发生时间差异较大，优先用可观测事件分阶段，再在物体相对坐标下提取模式；夹爪的离散状态也应与连续运动分别建模。

原始 action 模式的候选是 64×7 的动作信号，但时间重采样和连续夹爪值仍需执行适配。末端位置、相对位置、平移动作或累加示意模式只导出相应候选信号，不宣称它们是可直接执行的 7 维动作。

指令关系图比较各任务全集的共同成分与语言表征。Qwen3-4B 的末层平均池化是探索性语言特征，不是经过句子相似性校准的编码器；文本尚未参与子空间或条件采样器的训练。

训练数据与独立测试观察的导入格式

训练导入支持原分析台压缩 JSON，或如下完整轨迹格式。每个任务至少两条示范；data 各字段为时间优先的一维数组，长度为 T × dim。这些示范全部进入训练空间。

{"name":"my-demos","fields":[{"name":"action","dim":7},{"name":"eepos","dim":3}],
 "groups":["pick up the bowl"],
 "episodes":[{"id":0,"group":0,"T":64,
   "data":{"action":[...448 numbers...],"eepos":[...192 numbers...]}}]}

独立测试观察使用单独的按钮导入，不得包含 action 或轨迹。task 必须与当前任务指令完全一致；提供 eepos 或 context 至少一种。若同时提供两者，可以切换条件特征。

{"name":"scene-001", "task":"当前任务的完整英文指令",
 "eepos":[0.12, -0.08, 0.95],
 "context":[...与训练观察相同定义的特征...],
 "images":{"agent":"atlas-images/my-scene/agent.jpg"}}

内置 LIBERO 的 context 是 104 维：第 0 帧的 8 维机器人状态 + 环境相机 4×4×RGB 的 48 维 + 腕部相机同样的 48 维。RGB 缩放到 [0,1]，网格按行展开。必须与训练数据的坐标、通道、图像方向一致。这是粗粒度颜色基线，不是视觉语义编码。

图片仅允许相对路径 atlas-images/… 下的 JPG/PNG/WebP 或相应的 base64 data URL。导入数据只在浏览器读取。选用训练参考的观察时，会醒目标记“训练观察演示”，且参考示范仍在采样分布中，不能将它当成独立测试结果。

导出包括训练全集的示范 ID、尺度、均值、基底、当前 k、训练重建诊断、观察来源、采样参数、24 个候选系数及解码信号。没有测试真值、测试重建误差或执行成功率。
